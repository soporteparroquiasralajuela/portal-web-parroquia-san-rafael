## 1. Objetivo del documento

Registrar los requerimientos funcionales (qué debe hacer el sistema) del portal web, una vez levantados formalmente con la Parroquia como interesado principal.

## 2. Información disponible actualmente

Hasta la fecha **no se ha realizado un levantamiento formal de requerimientos funcionales**. Solo existe el marco tecnológico y arquitectónico definido en [CLAUDE.md](../../CLAUDE.md), y ejemplos de nomenclatura de páginas (ver [Alcance.md](../01_Gestion_Proyecto/Alcance.md), sección 5), que no constituyen requerimientos confirmados.

No se documentan funcionalidades específicas en este archivo para evitar inventar alcance no autorizado.

## 3. Secciones preparadas para ser completadas

### 3.2 Trazabilidad

Cada requerimiento funcional deberá, cuando se defina, enlazarse con:

- Su(s) caso(s) de uso en [Casos_de_Uso.md](Casos_de_Uso.md)
- Su(s) historia(s) de usuario en [Historias_de_Usuario.md](Historias_de_Usuario.md)
- El componente de arquitectura que lo implementa en [Arquitectura_General.md](../03_Arquitectura/Arquitectura_General.md)

## 4. Estado

**Pendiente.** Se completará durante la fase de Análisis del ciclo metodológico (CLAUDE.md sección 25), antes de iniciar cualquier implementación.
