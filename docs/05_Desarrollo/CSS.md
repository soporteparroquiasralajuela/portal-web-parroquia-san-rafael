## 1. Objetivo del documento

Establecer el estándar de escritura de CSS del proyecto.

## 2. Reglas vigentes

- Separar estilos por responsabilidad (archivos/organización clara dentro de `assets/css/`).
- Utilizar **variables CSS**.
- Utilizar nomenclatura consistente.
- Evitar CSS repetido.
- **No** utilizar estilos inline.
- **No** utilizar `!important`, excepto cuando sea estrictamente necesario.

## 3. Estado actual

`assets/css/` existe y está vacía; no hay hojas de estilo implementadas todavía. La paleta de colores y tipografía a expresar mediante variables CSS están pendientes (ver [Guia_Estilos.md](../04_Diseno/Guia_Estilos.md)).

## 4. Estado

**Vigente como norma.** Se aplicará desde la primera hoja de estilos que se cree.
